### Key Features:
* **Pixel Art Interface:** Buttons with custom pressed states and a themed design.
* **Solid Math Engine:** Support for basic operations (+, −, x, ÷).
* **Audio Effects:** Button press sound and background music.

### Tech Stack:
* **Language:** Kotlin
* **UI:** Jetpack Compose (Material 3 and external sprites)
* **Architecture:** MVVM
* **Logic / Math:** `Library exp4j` + Native Evaluator
* **Version Control:** Git / GitHub Flow
